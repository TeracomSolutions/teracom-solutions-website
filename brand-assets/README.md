# Brand assets

Original artwork for the Teracom Solutions brand, kept so the site's pictures can be made again. The site does not serve these files; it serves the optimised copies in `public/assets/` (for example `public/assets/teracom-logo.png`).

```text
brand-assets/
  2026-09-15-logo-refresh/     the September 2026 logo refresh
    TERACOM_Primary_Horizontal_Dark.png     the primary horizontal logo, for dark backgrounds
    Teracom Solutions Logo Text Side.png    the logo with the name beside the mark
    Teracom Solutions Logo No Text.png      the mark on its own
    Teracom Solutions Logo Design.png       the logo design sheet
    TERACOM_Brand_Concept_Preview.png       the brand concept preview
```

Each batch of artwork gets its own folder named `YYYY-MM-DD-what-it-is`. The Tera mascot and Teracom AI artwork are not here: they are in the graphics library on the server (VM 101, website-production, 10.0.0.101, `/home/teracom/graphics-library/`, catalogued in its `CATALOG.md`).
