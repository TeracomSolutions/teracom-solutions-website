# Documentation

| Document | What it covers |
|---|---|
| `seo/SEO_IMPROVEMENTS_REGISTER.md` | The living record of search-visibility work on teracomsolutions.com.au: what is done, what is planned and the expected effect. Updated in the same commit as each change. |
| `legal/README.md` | How the Terms and Conditions reach the site from the signed document, and what is needed to publish the PDF download. |

Other places:

- **Running and configuring the site:** the repository `README.md` and `.env.example`.
- **The backend, the database and the server:** the `teracom-website-backend` repository (`README.md` and `docs/`). Its `docs/architecture/` holds the architecture document for the whole website.
- **Original brand artwork:** `brand-assets/README.md`. The pictures the site serves: `public/assets/README.md`.
- **Console help for staff:** in the code, in `lib/adminGuide/` (the Help guide) and the `?` icon on each console page under `app/admin/`.
- **The server (VM 101, website-production):** `/home/teracom/README.md` on the server.

## Adding a document

Put it in a folder named for its subject (`seo/`, `legal/`, ...), name it in plain words, and add a row to the table above.
